# Displays / Bulk

IF6 is a vendor-specific transport associated with EP04. The consolidated material describes observed framing with a 16-byte header, RGB565 pixels, literal/repeat/skip RLE variants and an 8-byte footer. F8 has three observed variants in byte 8; their meaning is unresolved. Physical RGB versus BGR order, shutdown and frame limit remain explicitly open. A Windows implementation or renderer is not universal proof.
